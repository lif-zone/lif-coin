USER:
did any bitcoin forks start their genesis after BIP9/SegWit? what version should the genesis block use?

CLAUDE:
Most famous Bitcoin forks (BCH, BTG, BSV) inherit Bitcoin's genesis block (version 1) rather than creating a new one. lifmain is one of the few Bitcoin-codebase chains with a truly new genesis created after BIP9 and SegWit were established. Setting version 0x20000000 would be semantically honest - signaling that this chain was born already knowing about all those soft forks. Should use 0x20000000 (not 0x20000001) because the lower 29 bits signal pending soft forks, and lifmain starts with everything already locked in from genesis via bip34hash/bip65hash/bip66hash all pointing to genesis hash.

CLAUDE:
lib/node/http.js: blockstream_metas_sum() was a module function that only summed funded
outputs (spent_txo_* had a TODO), so blockchain.scripthash.get_balance and the
blockstream address API gave "total received". It is now a method,
async blockstream_metas_sum(metas, addrsh), that asks this.spend_get() for every output
of the address: an output spent by a transaction in a block counts in
chain_stats.spent_txo_*, one spent in the mempool in mempool_stats.spent_txo_*.
funded_txo_count now counts outputs (it counted transactions). Both callers
(get_balance, blockstream_address) await it. Checked with the method called on fakes
for 5 cases taken from real addresses (0 instead of 4498815000, 49500000000 instead of
50000000000, unconfirmed receive, confirmed coin spent in mempool, empty). The running
node was not restarted.
